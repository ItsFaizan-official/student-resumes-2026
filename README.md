## 📌 About This Repository
This repository contains resumes of students for academic, placement, and portfolio purposes.

📁 Each student has their own folder  
📄 Upload your latest resume  
🔄 Keep updating regularly  

---

## 🧑‍🎓 Student Structure

```

students/
├── your-name/
│    └── resume.pdf

````

---

## 🚀 How to Upload Your Resume

```bash
# Clone the repository
git clone https://github.com/your-username/student-resumes-2026.git

# Go inside folder
cd student-resumes-2026

# Add your files
git add .

# Commit changes
git commit -m "Added resume - Your Name"

# Push changes
git push origin main
````

---

## ⚠️ Important Rules

✅ Always pull before pushing
✅ Use your own folder only
✅ Keep file name as `resume.pdf`
✅ Do not modify others' files
